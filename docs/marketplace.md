# CodeMesh

A VS Code / Cursor coding-agent workbench for role-based, multi-model software engineering workflows.

CodeMesh assigns repository exploration, implementation, and review to independently configured models while sharing a controlled typed-tool layer and an auditable execution trace.

## Highlights

- Explorer → Coder → Reviewer workflow with a bounded revision loop
- OpenAI-compatible hosted and local model endpoints
- Zod-validated search, read, symbols, diagnostics, patch, and command tools
- Explicit diff preview and approval before edits
- Chat, Models, Flow, and Trace views
- VS Code SecretStorage for API keys

Open the CodeMesh activity-bar view, configure a model in **Models**, assign all three roles, and run a task from **Chat**.
